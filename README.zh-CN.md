# All Path Trading Agent

**开源、自部署、基于 LLM 的中长线交易 agent —— 它了解你的目标，与你共创策略，盯盘监控，通过你自己的券商账户执行交易，并与你共同成长。**

[English](README.md) · MIT 协议 · 包名：`tradewind`

> **当前状态：** Phase 1（执行地基）已完成——券商连接、行情数据、风控守门、交易日志和 CLI 已可对接 Alpaca 模拟盘账户。LLM agent 核心、策略引擎、记忆系统和 Web UI 在下方[路线图](#路线图)中。**默认仅模拟盘（paper trading）。**

## 这是什么？

大多数 LLM 交易项目止步于"给出分析"；大多数量化框架能执行代码却不会推理。All Path Trading Agent 把两者打通，专为**中长线投资**（以周和月为单位，而非高频）设计：

- **与你对话**，了解你的风险偏好、资金状况、投资目标和习惯
- **共创策略**——每份策略是一份人机双读的文档：投资论点（prose）+ 确定性的建仓/止盈/止损规则（机器可校验）
- **定时盯盘**，规则触发时自己去搜索最新新闻和价格做研究，像一位尽职的分析师，然后再行动
- **通过你自己的券商账户执行**，授权级别由你掌控：仅通知 → 确认后执行 → 额度内自动执行
- **与你共同学习**——交易后复盘、随时间加深的个股档案、以及沉淀下来影响未来决策的经验教训

## 工作原理

### 三个循环

1. **对话循环**（随时）：与 agent 聊股票、制定或修订策略。策略变更永远遵循 *agent 起草 → 你确认 → 生效*。
2. **哨兵循环**（盘中每 2 小时，可配置）：廉价的确定性代码把价格和策略规则逐条比对——没有触发时零 LLM 成本。触发后：**硬规则**（如止损）立即执行，全程无 LLM 参与；**软规则**（如逢低加仓）唤醒 agent 先联网研究当下状况，再按你的授权级别行动。
3. **反思循环**（每日收盘后 + 每笔交易后）：agent 用最新信息重新检验每个策略的投资论点、审视组合风险、给你发报告，并把经验沉淀进记忆。

### 安全模型——LLM 永远无法绕过你的限制

```
LLM / 策略规则  →  订单意图  →  风控守门（确定性代码）  →  券商（官方 SDK）
                                    │
                              交易日志（SQLite 审计）
```

- 每笔订单必须通过**确定性风控守门**——单笔金额上限、单股仓位上限、当日交易次数上限、现金储备——由普通代码硬性执行，LLM 没有任何旁路。通往券商的代码路径全仓库只有一条。
- **模拟盘优先**：真实交易默认关闭，需显式开启（`allow_live`），开启后依然受守门约束。
- **硬止损不经过 LLM**——不会因为模型幻觉或 API 宕机而失灵。
- 每笔交易、拒单和错误都连同完整决策理由记录在本地，供审计与复盘。

### 四层记忆

| 层 | 内容 |
|---|---|
| 用户画像 | 风险偏好、目标、决策习惯（缓慢演化） |
| 策略记忆 | 每个策略的完整版本历史与修订原因 |
| 个股档案 | 随时间累积的单票知识：行为特征、交易史、个股专属教训 |
| 经验教训 | 复盘沉淀的洞见，新决策时按相关性检索 |

## 为什么自部署、开源？

你的钱、你的密钥、你的机器：

- **Credentials 永不离开你的电脑**——LLM 和券商密钥存在本地 `.env`（已 gitignore），不会上传到任何地方
- **自带 LLM**——Claude（Anthropic）、OpenAI 或 OpenRouter（一个 key 可用多家模型，测试默认）
- **自带券商**——薄且可审计的适配层（官方 `alpaca-py` SDK 外面几百行代码），一次就能读完；欢迎通过 `Broker` 接口贡献更多券商
- **MIT 协议**——随意使用、fork、二次开发。没有托管服务，不收集数据，没有附加条件

## 快速上手（Phase 1）

1. 安装 [uv](https://docs.astral.sh/uv/)，然后：

   ```bash
   uv sync
   ```

2. 把 `.env.example` 复制为 `.env`，填入你的 [Alpaca 模拟盘账户](https://app.alpaca.markets/paper/dashboard/overview)密钥（免费）。

3. 验证连接：

   ```bash
   uv run tradewind status
   ```

   你会看到模拟盘账户的净值、持仓和最近的交易日志。

## 路线图

- [x] **Phase 1 —— 执行地基**：券商抽象 + Alpaca（模拟盘）适配器、行情数据（yfinance）、确定性风控守门、SQLite 交易日志、订单执行器、CLI

- [ ] **Phase 5 —— Web UI + 通知**：聊天 + 仪表盘 + 待确认队列 + 设置页、邮件通知
- [ ] **Phase 6 —— 反思循环**：每日深度 review、交易后复盘

## 开发

```bash
uv run pytest                  # 单元测试
uv run pytest -m integration   # 需要环境变量里有 Alpaca 模拟盘密钥
uv run ruff check .
```

技术栈：Python ≥3.11、pydantic v2、alpaca-py、yfinance、SQLite、pytest。核心为同步代码（中长线交易不需要 async）。钱一律用 `Decimal`，绝不用 float。

## 参与贡献
