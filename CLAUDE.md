# AllPath Trading Agent — Project Rules

## Git Workflow

### Merge & Explain Workflow
When asked to fix and merge: (1) fix on a branch, (2) run the full test suite and an independent evaluator pass, (3) rebase or merge onto the latest origin/main, resolving conflicts with any parallel work, (4) re-run full verification after the merge, (5) push main, (6) end with a short plain-language explanation for a non-specialist: what broke, why, and what the fix does.
