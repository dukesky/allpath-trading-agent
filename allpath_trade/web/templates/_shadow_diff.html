{# Shared before/after mini-table for a `shadow_edit` review row -- used by both the in-app review card (_review_card.html) and the unauthenticated approve-link confirm page (approve_confirm.html), so the two surfaces can never render a ledger edit's before/after differently. Two shapes: a flat op (set_position/set_cash/remove_position/record_fill) snapshots a handful of scalar fields (qty/avg_cost/cash/fill_price/...); a bulk op (import/reset) snapshots the WHOLE book (`{"positions": {...}, "cash": ...}`), which would be an unreadable wall of rows if flattened the same way -- rendered instead as position-count + cash summary rows. Detected by the presence of a `positions` key rather than by op name, so this macro stays correct even if a future op reuses either shape. #} {% macro shadow_before_after(before, after, op='') %} {% set is_bulk = (before is mapping and 'positions' in before) or (after is mapping and 'positions' in after) %}

A ticker counts as "being set" if its after-value differs from (or is new relative to) its before-value -- tickers the CSV didn't mention are untouched and correctly excluded. #} {% if op == 'import' %} {% set changed = [] %} {% for ticker, pos in a.positions.items() %} {% if b.positions.get(ticker) != pos %} {% set _ = changed.append(ticker) %} {% endif %} {% endfor %} {% if changed %} {% set changed_sorted = changed | sort %} {% endif %} {% endif %} {% else %} {% set fields = ['ticker', 'side', 'qty', 'avg_cost', 'cash', 'fill_price'] %} {% for k in fields %} {% if (before and k in before) or (after and k in after) %} {% endif %} {% endfor %} {% if not before and not after %} {% endif %} {% endif %}
