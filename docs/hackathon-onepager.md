# AllPath Trading Agent — Technical One-Pager

**Options Alpha Agents · Alpaca AI Trading Agents Hackathon** · [github.com/dukesky/allpath-trading-agent](https://github.com/dukesky/allpath-trading-agent) (MIT, 2,368 tests) · Live run: fresh $100k paper account, one kickoff chat, then five days hands-off.

## AI Logic — the LLM plans; code trades

**Three model tiers, one agent.** `CHAT_MODEL` (claude-sonnet-5) handles conversation, research, and strategy drafting; `REVIEW_MODEL` (haiku) analyzes soft-rule triggers; `MEMORY_MODEL` (claude-opus-5) runs nightly reflection and memory consolidation — the highest-stakes writes get the strongest model.

**Strategies are the interface between model and machine.** The agent writes YAML documents: a prose *thesis* plus deterministic *rules* — conditions compiled by a whitelist-AST evaluator (no `eval`) over `{price, position_qty, position_weight, avg_entry_price, pnl_pct}`, and actions in a closed grammar (`buy $3000`, `sell all`, `buy_call $1500 dte>=5 otm=3%`, `close_options`). A scheduled sentinel evaluates every armed rule each 30 minutes at **zero LLM cost**; triggers are one-shot (burned until explicitly re-armed). In the competition week, every rule was `hard` — **the intraday trading path contained no LLM calls at all**. The model's inference budget went to thinking: a bounded nightly reflection session (12 tool calls, wall-clock deadline) reviews the day against each thesis, writes lessons into four layers of curated markdown memory, re-arms spent triggers, and proposes strategy revisions as diffs. Revisions apply through one guarded pipeline: byte-exact base-staleness check, strict version increase, and a freeze that bars reflection from ever touching `authorization` or `status` — the agent cannot promote itself to more autonomy. Result over 5 days: **12 self-revisions auto-applied** — night one it found a stop→re-entry loop in all five of its own strategies; mid-week it invented salvage rules that recovered **~$1,165** of decaying option premium; its final report critiqued its own stop placement.

## Risk Gates — deterministic, non-bypassable

`Executor.execute()` / `execute_option()` are the **only** code paths that reach a broker; the LLM can only produce intents. Every intent passes a plain-code gate: per-order value ≤ $5,000 · resulting position weight ≤ 25% · **total options exposure ≤ 10% of equity** · cash-reserve floor · shared daily trade cap. Asymmetry by design: sells and option closes are exempt from value caps — **risk reduction is never blocked**. Above the per-order gate sit account-level controls: a **drawdown circuit breaker** (peak-tracked equity; −15% trips once → every `auto` strategy demotes to `confirm`, alerts on all channels, exits still execute), a **DTE ≤ 1 expiry sweep** (no option ever rides into exercise), **market-hours discipline** (closed-market option triggers stay armed instead of burning into venue rejections), and **honest failure** (a broker response without an order id journals an `error` and pages the operator — never a phantom "submitted"; this guard caught a real pre-market rejection on day one). Authoring-time validation completes the loop: option actions require `authorization: auto` + hard rules, and any strategy with option entries must carry paired `close_options` exits.

## Alpaca Infrastructure

**Stocks:** `alpaca-py` `TradingClient` (paper), hardened with socket timeouts bound onto its session; notional market orders, immediate fill-poll, full journaling. **Options: 100% through Alpaca's official MCP server** (`uvx alpaca-mcp-server`, stdio) run as a managed subprocess — lazily spawned, per-spawn ownership handles, one auto-respawn on transport failure, 30 s call timeouts, clean teardown on exit and config rebuilds. Contract selection is deterministic code, not model whim: `get_option_contracts` (expiry ≥ today+dte, right) → nearest expiry → strike closest to `spot×(1±otm)` → `get_option_latest_quote` → `qty = ⌊budget / (ask×100)⌋` → `place_option_order` (single-leg, `buy_to_open`/`sell_to_close`, market/day). Every trade, rejection, skip, LLM decision, and nightly report lands in a local SQLite journal — **the audit trail is the demo**.

**Week scoreboard (honest):** 17 rule-driven fills · 0 human trading decisions after kickoff · −4.9% ($95,138): stock book ≈ flat (−$180), the 5-DTE options overlay paid −$4.7k tuition — a flaw the agent diagnosed in writing on night one and spent the week correcting itself.
