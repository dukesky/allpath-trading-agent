How it works

Three loops, one process

On demand

Conversation

Web, Telegram, or CLI. The agent interviews you, researches live data, and drafts strategies as readable YAML — thesis in prose, rules as code. Anything touching money becomes an approval card.

Every 30 min · zero LLM cost

Sentinel

Plain code evaluates every rule against live quotes. Hard rules execute with no model in the path; soft rules wake a cheap review agent to research before deciding.

Nightly · after close

Reflection

A bounded agent session reviews the day against every thesis, writes lessons to curated memory, re-arms spent triggers, and revises its own strategies — as guarded diffs.

rule fires → contract selected via Alpaca MCP → risk gate (deterministic) → order → journal → push receipt → nightly reflection

Self-evolution

It found its own bug — and fixed it.

Every night, reflection reviews the day against each strategy's thesis, writes lessons into curated markdown memory (profile · strategies · stock dossiers · lessons), and proposes revisions as diffs — version-checked, byte-exact against the file they were written for, and frozen out of touching authorization.

Day one: option entries gated on “no position yet” were permanently disabled once the stock legs filled. Told what happened, the agent rewrote its own entry conditions across four strategies, kept the price ceilings after re-verifying them against live quotes, and re-armed the rules. The calls filled the same session.
Safety model

The LLM can never bypass your limits

✓
One path to the broker — the executor is the only submitting code; the model can only produce intents
✓
Deterministic risk gate — order value, position weight, options exposure, cash reserve, daily cap
✓
15% drawdown circuit breaker — halts new risk on every channel; exits still execute
✓
Risk reduction is never blocked — stop-losses and option closes are exempt from value caps
✓
Expiry sweep — options with ≤1 day to expiry are closed automatically
✓
Market-hours discipline — closed-market option triggers stay armed instead of burning
✓
No self-promotion — reflection can never flip a strategy to auto; only a human can
✓
Stale writes refused — byte-exact base checks and strict version increase on every revision
✓
Honest failure — a response without an order id journals an error and alerts, never a phantom fill
✓
Hard rules survive outages — stop-losses run with no LLM in the path
